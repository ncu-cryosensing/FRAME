# Using and Citing FRAME

FRAME is an open-source tool released under the [MIT License](https://github.com/ncu-cryosensing/FRAME/blob/dev/LICENSE). The source code is available on [GitHub](https://github.com/ncu-cryosensing/FRAME) and is open for external pull requests. 

## Citing FRAME

We are currently working on a formal publication of FRAME. Before that happens, we appreciate it if you could consider citing FRAME using this entry as a reference:

Panuntun, I. A., Zheng, W., & Ni, C.-F. (2025). TaiPI Data Repository: An Asia-Based, Community-Driven Platform Leveraging Emerging Technologies for Open Polar Science. 2025 AGU Fall Meeting (December 15-19).
